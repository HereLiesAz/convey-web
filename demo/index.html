A framework-agnostic TypeScript port of convey — Compose Multiplatform's motion grammar, visual-weight enforcement, and "replaces X" mechanisms, rebuilt on Custom Elements, Shadow DOM, and the Web Animations API. No React, no build step required to use it.

ConveyWeight

Visual hierarchy the framework enforces

<convey-weight weight="hero"> registers into the nearest <convey-system>. Two Heroes on one surface is a declared violation, not a style preference — the registry throws when the rule is broken.

One Hero, bounded Primaries, quiet Secondaries and Ghosts
Adding a second weight="hero" inside this system throws a ConveyViolationError — try it in the console: document.querySelector('convey-system').weightRegistry.register({}, 'hero') after this page registers its own hero above.

"Replaces X" mechanisms

Escort, Reversal, Yield, Migration, Offer

Each of these replaces a conventional UI construct — disabled buttons, confirm dialogs, spinners, empty-state illustrations — with one element that stays honest about what it's doing, in place.

convey-escorted — replaces disabled buttons
Submit is gated on the email field being non-empty. Click it empty — it refuses and escorts you to the field instead of doing nothing.
convey-reversal — replaces confirm dialogs
Delete a message: it collapses to an "Undo" residue for 4s instead of a confirm dialog.
convey-yield — replaces spinners
The button itself fills and compresses while working — no separate spinner appears.
convey-migration — replaces empty-state illustrations
Empty: the "+" control sits centered, full-size. Add an item: it relocates to the corner and shrinks — permanently.
convey-offer — the framework's Act, offered
Send Invoice Sending… ✓ Sent Retry
One element renders Invite → Progress → Success — no separate spinner, no separate toast.

Get started

Drop it into anything

Vanilla HTML, React, Vue, Svelte — convey-web is plain Custom Elements underneath.

npm install @hereliesaz/convey-web
import '@hereliesaz/convey-web/style.css'
import { ConveyMotion, springToLinearEasing } from '@hereliesaz/convey-web'

el.style.transitionTimingFunction = springToLinearEasing(ConveyMotion.Snappy)
